# Legal notice

**Tomodachi LTD Recomp** is an **educational and experimental** project. It studies how a console game's code can be turned into a native PC program through static recompilation.

## What this project contains

- An **installer** and tools written by this project.
- **Patches** (fixes) for the free software suyu/mk8-recomp, licensed under the GPL.
- Technical data used to **check the game version** (build identifiers and checksums). It contains no game content.

## What this project does NOT contain or provide

- **No game files**: no code, images, sounds, text, models or data.
- **No Nintendo encryption keys, firmware or BIOS.**
- **No prebuilt game executable.** The native build is always generated **on the user's computer**, from **that user's own copy**.

## Responsible use

- Use it **only** with a copy of the game that **you bought**, with the game file and keys dumped from **your own console**.
- **Do not share** the folder the installer generates (`local/`): it contains game data and translated game code.
- This project **does not help** anyone obtain games, keys or firmware from other sources, and such requests will be ignored.
- Follow the laws of your country. In some places, dumping or modifying software you own may be restricted.
