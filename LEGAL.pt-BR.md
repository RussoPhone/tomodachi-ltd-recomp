# Aviso legal

**Tomodachi LTD Recomp** é um projeto **educacional e experimental**. Ele estuda como transformar o código de um jogo de console num programa nativo de PC por recompilação estática.

## O que este projeto contém

- Um **instalador** e ferramentas escritas por este projeto.
- **Patches** (correções) para o software livre suyu/mk8-recomp, licenciado sob a GPL.
- Dados técnicos usados para **conferir a versão** do jogo (identificadores de build e somas de verificação). Eles não contêm conteúdo do jogo.

## O que este projeto NÃO contém e não fornece

- **Nenhum arquivo do jogo**: código, imagens, sons, textos, modelos ou dados.
- **Nenhuma chave de criptografia, firmware ou BIOS** da Nintendo.
- **Nenhum executável do jogo já pronto.** A versão nativa é sempre gerada **no computador de quem usa**, a partir da **própria cópia** dessa pessoa.

## Uso responsável

- Use **somente** uma cópia do jogo que **você comprou**, com o arquivo e as chaves extraídos do **seu próprio console**.
- **Não compartilhe** a pasta gerada pelo instalador (`local/`): ela contém dados e código traduzido do jogo.
- Este projeto **não ajuda** a obter jogos, chaves ou firmware de outras fontes, e pedidos assim serão ignorados.
- Respeite as leis do seu país. Em alguns lugares, extrair ou modificar software que você possui pode ter restrições.

## Marcas
