# Controls

🇧🇷 [Português](CONTROLS.pt-BR.md)

The game is played as on a docked Switch. The launcher's **Controls** button shows this table too.

## Keyboard

| Switch | Key |
|---|---|
| Left stick | **I** (up) · **K** (down) · **J** (left) · **L** (right) |
| Right stick (camera) | **Q** (left) · **E** (right) |
| D-pad | Arrow keys |
| A | **X** |
| B | **Z** |
| X | **S** |
| Y | **A** |
| L / R | **W** / **R** |
| ZL / ZR | **1** / **3** |
| + / − | **Enter** / **Backspace** |
| Close the game (HOME) | **Home** |
| Fullscreen | **F11** |

## Mouse (experimental)

> **Experimental and awkward.** The mouse works well on the island and poorly in some menus (the Mii creator in particular). It will be
> improved over time; the keyboard and controller work everywhere.

| Action | Mouse |
|---|---|
| Move the island camera | Push the mouse against the **edge of the window** for a moment (like a strategy game), or **drag with the middle button** (Shift + drag turns and zooms) |
| Zoom in / out on the island | **Scroll wheel** up / down (it pushes the right stick up / down). `NXRT_WHEEL_INVERT=1` swaps the direction |
| Touch screen (drawing, tapping buttons) | **Left click** and drag |
| Back / cancel (B) | **Right click** |
| Capture the mouse as an analog stick | **F8** (again to release). Where the game shows its hand (market, Mii house) the hand follows the mouse; on the island it moves the camera; in other menus it sends stick flicks. **F6 / F7** change the sensitivity; the longer you keep moving the same way the faster it goes (`NXRT_MOUSE_ACCEL`) |
| Turn off the edge scrolling / the hand following | `NXRT_EDGE_SCROLL=0`, `NXRT_MOUSE_HAND=0` |

## Controller

A Nintendo-style layout is used: the button on the **right** of the face buttons is A (on an Xbox pad that is B), the **bottom** one is B.

| Switch | Controller |
|---|---|
| A / B / X / Y | right / bottom / top / left face button |
| L / R, ZL / ZR | bumpers, triggers |
| + / − | Start / Back |
| Sticks, stick clicks, D-pad | the same on the pad |
| Close the game (HOME) | Guide / Home button |

Remapping is not available yet.
