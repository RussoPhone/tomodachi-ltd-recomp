# Controles

🇬🇧 [English](CONTROLS.md)

O jogo é jogado como num Switch na base. O botão **Controls** do launcher mostra esta tabela também.

## Teclado

| Switch | Tecla |
|---|---|
| Analógico esquerdo | **I** (cima) · **K** (baixo) · **J** (esquerda) · **L** (direita) |
| Analógico direito (câmera) | **Q** (esquerda) · **E** (direita) |
| D-pad | Setas |
| A | **X** |
| B | **Z** |
| X | **S** |
| Y | **A** |
| L / R | **W** / **R** |
| ZL / ZR | **1** / **3** |
| + / − | **Enter** / **Backspace** |
| Fechar o jogo (HOME) | **Home** |
| Tela cheia | **F11** |

## Mouse (experimental)

> **Experimental e esquisito.** O mouse funciona bem na ilha e mal em alguns menus (o criador de Mii em especial). Vai melhorar com o tempo;
> o teclado e o controle funcionam em tudo.

| Ação | Mouse |
|---|---|
| Mover a câmera da ilha | Encostar o mouse na **borda da janela** por um instante (como num jogo de estratégia), ou **arrastar com o botão do meio** (Shift + arrastar gira e dá zoom) |
| Zoom na ilha | **Roda do mouse** para cima / para baixo (empurra o analógico direito para cima / baixo). `NXRT_WHEEL_INVERT=1` inverte o sentido |
| Tela de toque (desenhar, tocar em botões) | **Clique esquerdo** e arrastar |
| Voltar / cancelar (B) | **Clique direito** |
| Capturar o mouse como analógico | **F8** (de novo para soltar). Onde o jogo mostra a mão (mercado, casa do Mii) a mão acompanha o mouse; na ilha ele move a câmera; em outros menus manda toques de analógico. **F6 / F7** mudam a sensibilidade; quanto mais tempo você mexe no mesmo sentido, mais rápido vai (`NXRT_MOUSE_ACCEL`) |
| Desligar a rolagem pelas bordas / a mão seguindo o mouse | `NXRT_EDGE_SCROLL=0`, `NXRT_MOUSE_HAND=0` |

## Controle

Usa o layout da Nintendo: o botão da **direita** entre os botões de ação é o A (num controle de Xbox, é o B), o de **baixo** é o B.

| Switch | Controle |
|---|---|
| A / B / X / Y | botão direito / de baixo / de cima / esquerdo |
| L / R, ZL / ZR | bumpers, gatilhos |
| + / − | Start / Back |
| Analógicos, cliques dos analógicos, D-pad | os mesmos no controle |
| Fechar o jogo (HOME) | botão Guide / Home |
